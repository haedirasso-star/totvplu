# totv.app — موقع توتيفي TOTV+ الرسمي

موقع ثابت يعمل على GitHub Pages مع الدومين `totv.app`.

## البنية

| الملف | الغرض |
|---|---|
| `index.html` | الرئيسية — الواجهة، المزايا، الخطوات، الأسعار |
| `download.html` | التحميل — اختيار الجهاز وحل الآيفون |
| `guide.html` | شرح التثبيت والتفعيل (هاتف / شاشة / آيفون) |
| `faq.html` | 18 سؤالاً شائعاً مع بيانات منظّمة لجوجل |
| `support.html` | قنوات الدعم والتواصل |
| `assets/totv.css` | نظام التصميم كاملاً |
| `assets/totv.js` | ★ كل الروابط والباقات — عدّلها من هنا فقط |
| `assets/footer.js` | التذييل المشترك |

## ★ تعديل الروابط

كل الروابط في مكان واحد: `assets/totv.js` أعلى الملف.

```js
links: {
  whatsapp: 'https://wa.me/9647714415816',
  telegram: 'https://t.me/O_2828',    // قناة الأخبار
  telegramSupport: '',                 // اتركه فارغاً ليختفي الزر
  facebook: '', instagram: '', tiktok: '', youtube: '',
}
```

**الروابط الفارغة تختفي تلقائياً** من التذييل وصفحة الدعم — لن تظهر أزرار معطّلة.

## تعديل الأسعار

في نفس الملف:

```js
plans: [
  { name:'شهر', price:'5,000', per:'شهر واحد', save:'', popular:false },
  ...
]
```

## تغيير ملف نسخة الشاشات

```js
fileTV: 'totvplus.apk',   // بدّلها إلى totvplus-tv.apk عند رفعها
```

الروابط تستخدم `releases/latest` فلا تتعطّل عند إصدار نسخة جديدة.

## ملاحظات تقنية

- **الخطوط:** IBM Plex Sans Arabic + IBM Plex Mono
- **البوسترات:** تُجلب من TMDB وقت التصفّح. إن فشل الطلب يختفي الشريط بلا أثر.
- **كشف الجهاز:** يُبرز النسخة المناسبة تلقائياً حسب المتصفح.
- **الحركة:** المحتوى ظاهر افتراضياً؛ الإخفاء يُفعَّل فقط عند تأكّد عمل JS،
  مع شبكة أمان تُظهر كل شيء بعد ثانيتين. لا تُوجد حالة تجعل الصفحة فارغة.
- **إمكانية الوصول:** تباين مناسب، تركيز واضح بلوحة المفاتيح، واحترام
  `prefers-reduced-motion`.
